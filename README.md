# wowfa2: WoWFA v1 source

Persian translation addon for WoW Forever. Private source; releases are published (as drafts the owner
approves) in the public repo pvwvuow/wowfarsi-addon.

- How it is built and why: docs/ARCHITECTURE.md
- One-time owner setup: docs/OWNER_SETUP.md
- Everything runs through `python3 tools/ci.py` (ci | check | build | tasks).

Data from ForeverDB.net (https://foreverdb.net). Font: Vazirmatn (SIL OFL 1.1).
